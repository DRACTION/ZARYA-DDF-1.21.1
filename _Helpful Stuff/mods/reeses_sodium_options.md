## Описание

Удобное меню видеонастроек для Sodium: вкладки, поиск и прокрутка вместо одной длинной страницы.

## Заметки

Требует Sodium ровно 0.8.13 (`[0.8.13+mc1.21.1]`). Объявлен несовместимым с Sodium Options API (sodiumoptionsapi), поэтому тот убран из сборки. Controlify — опционально.
