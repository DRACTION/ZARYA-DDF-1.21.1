# Карточки модов

Одна карточка на мод: `<modid>.md`. В начале файла идёт YAML-блок:

```yaml
---
name: 'Название'
modid: 'modid'
file: 'имя-файла.jar'
version: '1.2.3'
modrinth: 'https://modrinth.com/mod/...'
curseforge: 'https://www.curseforge.com/projects/...'
git: 'https://github.com/...'
category: 'Интерфейс и QoL'
---

## Описание

1–3 предложения: что мод делает в игре.

## Заметки
```

Описание и заметки ниже YAML-блока свободные, скрипт их не трогает.

## Категории

Поле `category` — ровно одна категория из списка. Порядок списка = порядок групп в `MODS.md` и фильтров на вкладке «Моды» в `Z@RYA.html`; сам список (с иконками) задан в `_Helpful Stuff/_common.ps1` (`$categories`, `$categoryMeta`).

- Create и аддоны
- Техника, хранение и логистика
- RPG, магия и прогрессия
- Бой и оружие
- Мобы и боссы
- Мир и генерация
- Структуры и подземелья
- Еда и фермерство
- Жители и животные
- Выживание и механики
- Транспорт и перемещение
- Декор и строительство
- Интерфейс и QoL
- Графика и анимации
- Звук и музыка
- Оптимизация и исправления
- Сервер, скрипты и утилиты
- Библиотеки и API
- Прочее
- Без категории

Новым карточкам скрипт ставит `Без категории` — замените на подходящую. Уже заполненную категорию скрипт не трогает. Категория не из списка попадёт в конец, скрипт выведет предупреждение.

## Шаблон

`_TEMPLATE.md` — шаблон карточки. Для нового мода скопируйте его в `<modid>.md` и замените плейсхолдеры (`{{name}}`, `{{modid}}`, `{{file}}`, `{{version}}`, `{{modrinth}}`, `{{curseforge}}`, `{{git}}`, `{{category}}`, `{{description}}`, `{{notes}}`). Подсказки в `<!-- ... -->` на GitHub не видны — их можно оставить или удалить.

Скрипт создаёт заготовки новых карточек по этому же шаблону: неизвестные плейсхолдеры заменяются пустой строкой, подсказки остаются. Меняйте раскладку карточек в шаблоне, а не в скрипте. Файлы на `_` и `README.md` карточками не считаются.

`_Helpful Stuff/Update MODS cards.ps1` (его вызывает `Update MD5 mods.ps1`):
- создаёт заготовки карточек для новых jar (по `_TEMPLATE.md`),
- обновляет `file`/`version` (`version` — только номер версии мода, без версии Minecraft и лоадера; берётся из `neoforge.mods.toml`, иначе из Modrinth, иначе из имени файла), пустые ссылки дозаполняет через Modrinth API (по sha1),
- заполненные вручную поля не перезаписывает,
- собирает `_Helpful Stuff/MODS.md` — таблицы со ссылками на карточки, сгруппированные по категориям в сворачиваемых блоках `<details>`,
- в конце вызывает `_Helpful Stuff/Update site.ps1`, который собирает страницу сборки `Z@RYA.html` в корне инстанса: вкладка «Моды» — та же таблица с поиском, фильтром по категориям, сортировкой и раскрытием карточек; плюс установка и помощь (из `README.md`), ресурспаки и музыка. Один файл, открывается в браузере без интернета.
