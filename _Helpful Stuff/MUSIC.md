<summary><b>Что означают параметры</b></summary>

По документации и исходникам Music Triggers 7.0.4. Время указывается в тиках: 20 тиков = 1 секунда.

- <code>identifier</code> — <b>Идентификатор</b>. Уникальное имя этого экземпляра события (нужно, когда событий одного типа несколько: biome, mob, dimension, riding, time, height…). На условия срабатывания не влияет — только группирует параметры и даёт ссылку вида <code>biome-ocean</code>, по которой к событию привязываются треки. <i>(строка; обязателен для таких событий)</i>
- <code>priority</code> — <b>Приоритет</b>. Приоритет относительно других событий, которые подходят одновременно: по умолчанию играет событие с наибольшим приоритетом. Если событий несколько (комбинация), общие параметры вроде fade_out берутся у события с наибольшим приоритетом. <i>(число; по умолчанию своё для каждого типа события)</i>
- <code>biome_category</code> — <b>Категория биома</b>. Устаревшее имя параметра из Music Triggers 6.x; в 7.x автоматически переименовывается в <code>biome_tag</code>. Категория/тег биома под игроком должен совпасть с одним из значений списка по правилу biome_tag_matcher. <i>(список строк; по умолчанию [any])</i>
- <code>biome_tag_matcher</code> — <b>Сравнение тега биома</b>. Как сравнивать biome_tag (biome_category): exact — точное совпадение, partial — частичное (подстрока), regex — регулярное выражение. <i>(exact / partial / regex; по умолчанию exact)</i>
- <code>detection_range</code> — <b>Радиус обнаружения</b>. Радиус вокруг игрока, в котором ищутся подходящие мобы. По вертикали проверяется доля этого радиуса (detection_y_ratio, по умолчанию 0.5). <i>(блоки; по умолчанию 16)</i>
- <code>fade_in</code> — <b>Нарастание</b>. Сколько тиков звук плавно нарастает после того, как событие стало активным. <i>(тики (20 тиков = 1 с); по умолчанию 0)</i>
- <code>fade_out</code> — <b>Затухание</b>. Сколько тиков звук плавно затухает, когда событие перестало быть активным. <i>(тики (20 тиков = 1 с); по умолчанию 0)</i>
- <code>level</code> — <b>Уровень (height)</b>. Для события height: Y-координата игрока должна быть больше этого значения (при check_above_level = true — меньше). При check_for_sky = true (по умолчанию) над игроком ещё и не должно быть видно неба — так получается «под землёй». <i>(блоки (Y); по умолчанию 0)</i>
- <code>mob_targeting</code> — <b>Моб нацелен на игрока</b>. Нужно ли, чтобы моб целился в игрока, чтобы событие сработало. В творческом режиме и режиме наблюдателя мобы игрока не выбирают целью. <i>(true / false; по умолчанию true)</i>
- <code>resource_matcher</code> — <b>Сравнение ID</b>. Как сравнивать resource_name: exact — точно, partial — частично (подстрока), regex — регулярное выражение. <i>(exact / partial / regex; по умолчанию partial)</i>
- <code>resource_name</code> — <b>ID ресурса</b>. ID (resource name) моба / измерения / транспорта должен совпасть с одним из значений списка по правилу resource_matcher. Особое значение <code>MOB</code> (по исходникам) — любой враждебный моб. <i>(список строк; по умолчанию [any])</i>
- <code>song_delay</code> — <b>Пауза между треками</b>. Устаревшее имя из 6.x; в 7.x — <code>ticks_between_audio</code>: сколько тиков ждать после окончания трека, прежде чем заиграет следующий из пула. <i>(тики (20 тиков = 1 с); по умолчанию 0)</i>
- <code>time_bundle</code> — <b>Период суток</b>. Готовый диапазон времени: night, day, sunrise или sunset (параметры start_hour/end_hour тогда игнорируются). Любое другое значение, например any, отключает его. <i>(night / day / sunrise / sunset; по умолчанию any)</i>
- <code>trigger_delay</code> — <b>Задержка звука</b>. Устаревшее имя из 6.x; в 7.x — <code>ticks_before_audio</code>: сколько тиков после активации события пройдёт, прежде чем начнётся звук. <i>(тики (20 тиков = 1 с); по умолчанию 0)</i>

**Параметры треков** (<code>[songs.*]</code>):

- <code>play_once</code> — <b>Однократный трек</b>. Что происходит после проигрывания трека: 0 — ничего; 1 — не повторяется, пока не сыграют все треки пула или событие не отключится; 2 — пока событие не отключится; 3 — до выхода из мира; 4 — только один раз за мир (даже после перезапусков); 5 — до перезапуска игры. <i>(0–5; по умолчанию 0)</i>
- <code>triggers</code> — <b>События трека</b>. События, к которым привязан трек. Если указано несколько — должны выполняться все сразу (И); для «ИЛИ» добавляют ещё одну запись трека. <i>(список; по умолчанию [])</i>
